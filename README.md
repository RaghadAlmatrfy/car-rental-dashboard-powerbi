# 🚗 Car Rental Dashboard — Power BI

لوحة معلومات تفاعلية في **Power BI** تحلّل بيانات تأجير السيارات لـ **الربع الثاني من عام 2026**.

An interactive **Power BI** dashboard analyzing car rental data for **Q2 2026**.

---

## 📊 محتوى اللوحة | Dashboard Overview

| العنصر | الوصف |
|---|---|
| 🔢 بطاقة عدد العقود | إجمالي عدد عقود الإيجار |
| 💰 بطاقة قيمة الإيجار | إجمالي قيمة الإيجار |
| 🥧 مخطط دائري | توزيع العقود حسب **حالة الحجز** |
| 📊 مخطط أعمدة | عدد العقود حسب **الفرع** |
| 📉 مخطط أشرطة | قيمة الإيجار حسب **نوع السيارة** |
| 🎛️ فلاتر (Slicers) | التصفية حسب **الفرع** و **نوع السيارة** |
